# Contributing

Thanks for helping improve Vercel Experiments.

## Development

```bash
pnpm install
pnpm dev
```

Before opening a PR:

```bash
pnpm run ci
```

## Adding experiments

Follow [EXPERIMENTS.md](./EXPERIMENTS.md).

## Pull requests

- Keep changes focused
- Include tests for non-trivial logic
- Update docs when behavior changes
- Do not commit secrets
