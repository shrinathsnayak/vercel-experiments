RSS Digest Lab fetches an RSS/Atom feed (capped), parses top-N items locally, and returns one-sentence digests via `generateObject`. Pass `regenerate: true` to refresh wording with `cache: no-store`.

## Features

- **Feed parse in `logic.ts`** – RSS item/entry + CDATA heuristics
- **Top-N digests** – clamped 1–10
- **Regenerate** – same endpoint with fresh prompt angle

## Server Reference

### `POST /api/digest`

```json
{ "feedUrl": "https://nextjs.org/feed.xml", "topN": 5, "regenerate": false }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

### Route Handler

`POST /api/digest` validates input, applies fetch/parse limits where relevant, then returns JSON from `generateObject`.

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/rss-digest-lab/`. Wire your own persistence and auth as needed.
