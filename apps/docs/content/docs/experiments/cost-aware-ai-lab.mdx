Cost-Aware AI Lab runs one prompt on two models (default `gpt-4o-mini` vs `gpt-4o` via Gateway), then shows latency, token usage, and a rough USD **estimate** clearly labeled as an estimate - not billing truth. Missing AI keys return `503`.

## Features

- **Dual model compare** – parallel `generateText` runs.
- **Latency + tokens** – from AI SDK usage when available.
- **Labeled estimates** – public-rate heuristics, not invoices.
- **Honest `503`** when AI is not configured.

## Server Reference

### `POST /api/compare`

```json
{ "prompt": "..." }
```

#### Success (`200`)

```json
{
  "runs": [
    {
      "model": "openai/gpt-4o-mini",
      "latencyMs": 420,
      "estimatedCostUsd": 0.0001,
      "estimateNote": "..."
    }
  ],
  "estimateDisclaimer": "..."
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Empty prompt |

## Implementation Details

<Steps>
<Step>

### Resolve two models

`AI_MODEL_A` / `AI_MODEL_B` or defaults.

</Step>
<Step>

### Estimate

`estimateCostUsd` from rough per-MTok tables - always labeled.

</Step>
</Steps>

## Use Cases

- Teach cost awareness in demos.
- Compare latency before picking a default model.

## Limitations

- Estimates are not Gateway invoices.
- Token counts depend on provider usage fields.
