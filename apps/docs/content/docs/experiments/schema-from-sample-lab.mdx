Schema from Sample Lab infers TypeScript types and Zod schemas from a JSON or CSV paste. `detectSampleKind` hints the prompt; the model returns code strings you can download as `types.ts` / `schema.ts`. No AI keys - `503`.

## Features

- **JSON or CSV samples** – one-click loaders.
- **Dual code output** – TypeScript + Zod strings.
- **Notes** – assumptions (optional fields, unions).
- **Download buttons** – save each string.
- **Honest unavailable state**.

## Server Reference

### `POST /api/schema`

```json
{ "sample": "{ ... }" }
```

#### Success (`200`)

```json
{
  "typescript": "export type User = { id: string; ... }",
  "zod": "export const UserSchema = z.object({ ... })",
  "notes": ["roles is string[]"],
  "detectedKind": "json",
  "provider": "ai-gateway"
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Empty sample |

## Implementation Details

`detectSampleKind` and `clampSchema` are pure helpers in `logic.ts` (unit tested).

## Use Cases

- Bootstrap Zod from API fixtures.
- Teach sample - schema composition.
- CSV column typing drafts.

## Limitations

- Sparse samples produce weak types.
- Does not validate generated code by compiling it.
- No auth / rate limits.

## Use in your project

Reuse the dual string schema from `app/api/schema/route.ts`.
