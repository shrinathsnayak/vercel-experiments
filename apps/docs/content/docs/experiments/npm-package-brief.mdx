npm Package Brief validates a package name, fetches registry + weekly download metadata (no install), then returns when-to-use / when-to-avoid guidance via `generateObject`.

## Features

- **Registry-only** – no `npm install`
- **Download stats** – last-week point API when available
- **Use/avoid brief** – grounded in metadata

## Server Reference

### `POST /api/brief`

```json
{ "packageName": "zod" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |
