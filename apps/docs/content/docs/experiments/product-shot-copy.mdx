Product Shot Copy is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Vision - title + bullets
- Optional OG ImageResponse URL
- Honest 503

## Server Reference

### `POST /api/copy · GET /api/og`

```json
multipart/form-data: file=<image>
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing image |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not a full PDP CMS.
- 4MB cap.
- OG uses generated text only.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/product-shot-copy/`.
