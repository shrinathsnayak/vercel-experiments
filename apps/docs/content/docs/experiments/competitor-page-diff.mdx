Competitor Page Diff fetches two public http(s) URLs with the same size/timeout caps as URL Brief Lab, extracts title/meta/text for each single page, and returns a structured messaging diff via `generateObject`. Missing AI keys return `503`.

## Features

- **Dual capped fetch** – parallel page fetches with timeout + byte limits
- **Structured messaging diff** – sharedThemes / aOnly / bOnly / positioningNotes
- **Honest `503`** when AI is unavailable

## Server Reference

### `POST /api/diff`

```json
{ "urlA": "https://a.com", "urlB": "https://b.com" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/competitor-page-diff/`. Wire your own persistence and auth as needed.
