Feature Request Board is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- generateObject clusters ideas into themes
- Redis/memory vote increments per cluster id
- Honest 503 without AI; memory note without Redis

## Server Reference

### `POST /api/cluster · POST /api/vote · GET /api/vote`

```json
{ "ideas": "dark mode\nexport CSV" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing ideas / clusterId |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not a full product board.
- Clustering quality depends on the model.
- Votes reset on cold start without Redis.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/feature-request-board/`.
