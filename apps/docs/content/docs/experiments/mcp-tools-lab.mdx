A standalone MCP-shaped tools endpoint that searches a **local experiment catalog snapshot**. The hub MCP at `apps/docs/app/api/mcp` indexes docs via fumadocs; this lab focuses on catalog tools you can deploy alone.

## Features

- tools/list and tools/call RPC shape
- search_experiments / get_experiment / list_experiments
- Local registry snapshot in logic.ts
- Interactive demo UI

## API Reference

### GET /api/mcp

Server info + tool schemas.

### POST /api/mcp

`{ method: "tools/list" | "tools/call" | "initialize", params? }`.

## Use Cases

- Agent tool servers
- Catalog search for AI clients
- Teaching MCP tool shapes

## Limitations

- Not the full MCP transport stack of the docs hub.
- Snapshot may lag the live registry.
- No auth on the demo endpoint.

## Use in your project

Deploy or copy `apps/experiments/mcp-tools-lab/` and adapt the Route Handlers and pure helpers in `logic.ts`. Keep honest fallbacks when optional services are missing.
