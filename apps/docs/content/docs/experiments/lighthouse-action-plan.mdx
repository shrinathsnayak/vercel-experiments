Lighthouse Action Plan parses pasted Lighthouse JSON for category scores and weak audits, then returns a prioritized Next.js-oriented fix list via `generateObject`.

## Features

- **Local audit extraction** – categories + weak audits before the model call
- **P0/P1/P2 plan** – Next.js-specific fix suggestions
- **Sample JSON** – performance/SEO-shaped fixture in `logic.ts`

## Server Reference

### `POST /api/plan`

```json
{ "lighthouseJson": "{ ... }" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

## Use Cases

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/lighthouse-action-plan/`. Wire your own persistence and auth as needed.
