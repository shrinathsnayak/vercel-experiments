Stack Trace Fixer detects common App Router hint patterns locally (server/client boundary, hydration, module resolution), then returns tips and a repro checklist via `generateObject`.

## Features

- **Local hint detection** – boundary / hydration / dynamic APIs
- **Next.js tips + repro checklist**
- **Docs topic hints** – keywords, not invented URLs

## Server Reference

### `POST /api/fix`

```json
{ "error": "...", "stack": "..." }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |



## Implementation Details

<Steps>
<Step>

### Pure helpers in `logic.ts`

Caps, parsers, and clamps live in the experiment folder and are covered by `logic.test.ts`.

</Step>
<Step>

### Route Handler

`POST /api/fix` validates input, applies fetch/parse limits where relevant, then returns JSON from `generateObject`.

</Step>
</Steps>

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/stack-trace-fixer/`. Wire your own persistence and auth as needed.
