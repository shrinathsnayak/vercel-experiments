Multi-Tenant Notes is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Resolve tenant from header or query
- Per-tenant note lists
- Neon/memory persistence

## API Reference

### `GET|POST /api/notes`

```json
{ "text": "Ship docs", "tenant": "acme" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing tenant/text |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not row-level security.
- No auth users.
- Memory resets on cold start.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/multi-tenant-notes/`.
