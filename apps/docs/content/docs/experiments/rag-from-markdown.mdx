Multi-file markdown RAG with keyword chunk retrieval and visible source chunks. Missing AI keys return `503`.

## Features

- Standalone Next.js app under `apps/experiments/rag-from-markdown/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## Server Reference

### `POST /api/ask`

```
{ "question": "...", "files": [{ "name", "content" }] }
```
