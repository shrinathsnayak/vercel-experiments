Paste Preview and Production env files, check required keys, and review redacted diffs before promoting.

## Features

- Standalone Next.js app under `apps/experiments/env-promotion-checklist/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## UI Reference

Client-side compare only — paste stays in the browser. No server secrets and no Route Handlers.

| Control | Behavior |
| --- | --- |
| Preview / Production paste | Parsed as env files in `logic.ts` |
| Required keys | Checklist of missing vs present (values redacted) |
