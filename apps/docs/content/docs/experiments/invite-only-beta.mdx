Invite-Only Beta is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Seed + redeem invite codes
- Allowlist membership check
- Redis/memory store

## API Reference

### `POST /api/invite · GET /api/invite`

```json
{ "code": "BETA-ACME", "email": "a@b.co" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Invalid / already used |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Fixed seed codes.
- No email invites.
- Demo-scale only.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/invite-only-beta/`.
