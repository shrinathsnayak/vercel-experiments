Repair broken JSON with deterministic heuristics first, optional AI fallback, and a simple line diff.

## Features

- Standalone Next.js app under `apps/experiments/json-repair-lab/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## Server Reference

### `POST /api/repair`

```
{ "json": "{...}" }
```
