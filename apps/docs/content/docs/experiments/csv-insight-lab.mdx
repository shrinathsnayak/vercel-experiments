CSV Insight Lab parses CSV in `logic.ts` (max 50 data rows), builds `chartReady` aggregates from numeric columns, then calls `generateObject` for insights grounded only in those rows. The model is instructed never to invent rows. Missing AI keys return `503`.

## Features

- **Local CSV parse** – quoted fields, row cap.
- **chartReady aggregates** – from parsed numeric columns only.
- **Insights + caveats** – generateObject schema.
- **Sample sales CSV** – product / units / revenue.
- **Honest `503`** when AI is unavailable.

## Server Reference

### `POST /api/insights`

JSON `{ "csv": "..." }` or multipart with `csv` + optional `file`.

#### Success (`200`)

```json
{
  "insights": ["Units peak on Blob Drop"],
  "caveats": ["Only 5 rows"],
  "chartReady": [{ "label": "Blob Drop", "value": 200 }],
  "rowCount": 5,
  "provider": "ai-gateway"
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Missing header/data rows |
