Extract structured form fields from free-form prose with confidence scores. Missing AI keys return `503`.

## Features

- Standalone Next.js app under `apps/experiments/structured-form-filler/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## Server Reference

### `POST /api/fill`

```
{ "prose": "..." }
```
