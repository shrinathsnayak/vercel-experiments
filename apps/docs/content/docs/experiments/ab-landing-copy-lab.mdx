A/B Landing Copy Lab uses `generateObject` to create two headlines, assigns visitors to sticky cookie buckets (`Set-Cookie`), and records impression/conversion counters in Redis or memory. Missing AI keys return `503`.

## Features

- **Two headlines** – A/B variants from a product topic.
- **Sticky cookie bucket** – `ab_landing_bucket` via `Set-Cookie`.
- **Funnel counters** – impressions + conversions with rates.
- **Honest `503`** when AI is not configured.

## Server Reference

### `POST /api/generate`

```json
{ "topic": "..." }
```

### `GET /api/assign`

Returns `{ bucket, headline }` and sets cookie when new.

### `POST /api/event`

```json
{ "bucket": "A", "type": "impression" }
```

### `GET /api/stats`

Funnel totals + conversion rates.

| Status | Cause |
| --- | --- |
| `503` | No AI provider (generate) |
| `400` | Invalid event payload |
