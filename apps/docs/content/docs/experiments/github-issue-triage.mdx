GitHub Issue Triage is paste-only: no GitHub token, no remote mutations. It returns kebab-case labels, severity, a first-response draft, and clarifying questions via `generateObject`.

## Features

- **No GitHub token** – never opens or labels issues remotely
- **Labels + severity** – maintainer-oriented triage
- **First-response draft** – polite, grounded in the issue text

## Server Reference

### `POST /api/triage`

```json
{ "title": "...", "body": "..." }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/github-issue-triage/`. Wire your own persistence and auth as needed.
