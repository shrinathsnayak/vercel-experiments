Chat that calls mock weather, time, and calculator tools and surfaces a structured tool-call trace. Missing AI keys return `503`.

## Features

- Standalone Next.js app under `apps/experiments/tool-calling-weather-demo/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.
