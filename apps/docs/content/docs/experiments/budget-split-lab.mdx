Budget Split Lab is a Batch G vertical mini composition lab. Pure helpers live in `logic.ts`; AI calls return an honest `503` when no provider is configured.

## Features

- Local splitEvenly math
- AI rationale
- Honest 503

## Server Reference

### `POST /api/split`

```json
{ "expenses": "..." }
```

| Status | Cause |
| --- | --- |
| `200` | Success (or stream) |
| `400` | Missing / invalid input |
| `503` | No AI provider (`AI_GATEWAY_API_KEY` or `OPENAI_API_KEY`) |




## Limitations

- Not banking software.
- Simple even-split helper.
- No multi-currency FX.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `AI_GATEWAY_API_KEY` | Yes (or OpenAI) | Preferred AI provider |
| `OPENAI_API_KEY` | No | Fallback |
| `AI_MODEL` | No | Model override |
