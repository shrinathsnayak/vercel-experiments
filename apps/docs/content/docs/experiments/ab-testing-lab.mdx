Assign visitors to variant A or B with a sticky `ve-ab` cookie, record impressions and conversions, and show conversion rates. Redis backs the funnel when configured; otherwise memory is used honestly.

## Features

- Sticky A/B cookie assignment
- Impression + conversion tracking
- Conversion rate display per variant
- Redis or memory backend
- Reset controls for demos

## API Reference

### GET /api/ab

Current funnel stats.

### POST /api/ab

Actions: `assign`, `convert`, `stats`, `reset`.

## Use Cases

- Simple cookie A/B tests
- Teaching experimentation funnels
- Comparing with Flags SDK labs

## Limitations

- Not statistically rigorous - teaching funnel only.
- Memory backend resets on cold start.
- No multivariate or holdout analysis.

## Use in your project

Deploy or copy `apps/experiments/ab-testing-lab/` and adapt the Route Handlers and pure helpers in `logic.ts`. Keep honest fallbacks when optional services are missing.
