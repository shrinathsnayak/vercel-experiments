Robots Policy Advisor accepts pasted `robots.txt` or an optional fetch URL (auto-appends `/robots.txt` for origins), parses allow/deny locally, and explains the policy with suggestions via `generateObject`.

## Features

- **Paste or URL** – fetch optional when paste empty
- **Local parse hints** – Allow / Disallow / Sitemap
- **AI advice** – allows, denies, suggestions, summary

## Server Reference

### `POST /api/advise`

```json
{ "robotsText": "User-agent: *\nDisallow: /api/", "url": "https://example.com" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Model quality depends on input clarity.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/robots-policy-advisor/`. Wire your own persistence and auth as needed.
