SEO Meta Auditor fetches a page (capped), extracts title/description/canonical/OG tags, computes local gaps, rewrites suggestions via `generateObject`, and exposes `/api/og` for an ImageResponse preview.

## Features

- **Meta extraction + local gaps** – title/description/canonical/OG
- **Rewritten suggestions** – title / description / OG fields
- **ImageResponse OG** – `/api/og?title=&description=`

## Server Reference

### `POST /api/audit`

```json
{ "url": "https://vercel.com/docs" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Validation / upstream / empty input |

### `GET /api/og`

Query: `title`, `description`. Returns a 1200×630 PNG via `ImageResponse`.
