Docs to FAQ Lab turns markdown into FAQ pairs via `generateObject`. When Upstash Redis env vars are present, results are cached by SHA-256 of the content with a TTL. Without Redis, every request regenerates (no fabricated cache hits). Missing AI keys return `503`.

## Features

- **Markdown - FAQ** – up to 12 Q/A pairs from capped docs.
- **Redis content-hash cache** – TTL cache when Redis is configured.
- **Cache miss transparency** – UI shows hit/miss and backend.
- **Sample docs** – Redis cache lab snippet.
- **Honest `503`** when AI is unavailable.

## Server Reference

### `POST /api/faq`

```json
{ "markdown": "# Title\n..." }
```

#### Success (`200`)

```json
{
  "faqs": [{ "question": "...", "answer": "..." }],
  "cached": false,
  "cache": "redis",
  "provider": "ai-gateway",
  "ttlSeconds": 3600
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Empty markdown |

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `AI_GATEWAY_API_KEY` | Yes (or `OPENAI_API_KEY`) | Preferred provider |
| `OPENAI_API_KEY` | No | Fallback |
| `AI_MODEL` | No | Model override |
| `UPSTASH_REDIS_REST_URL` | No | Cache |
| `UPSTASH_REDIS_REST_TOKEN` | No | Cache |
