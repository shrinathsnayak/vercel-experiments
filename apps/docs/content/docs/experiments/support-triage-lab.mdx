Support Triage Lab turns a pasted ticket into `{ category, priority, reply }` with `generateObject`. When Upstash Redis is configured it rate-limits requests; otherwise it skips the limit and shows a note. Missing AI keys return `503`.

## Features

- **Ticket - triage** – category, priority, draft reply.
- **Redis rate limit** – per-IP window when configured.
- **Honest `503` / `429`** – no fabricated model output; clear limit errors.

## Server Reference

### `POST /api/triage`

```json
{ "ticket": "..." }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `429` | Rate limit exceeded |
| `400` | Empty ticket |

## Implementation Details

<Steps>
<Step>

### Rate limit

Redis `INCR` + `EXPIRE` when available.

</Step>
<Step>

### Triage

`generateObject` with Zod schema for category/priority/reply.

</Step>
</Steps>

## Use Cases

- Prototype support automation.
- Learn rate-limit + AI composition.

## Limitations

- Heuristic categories are demo-scoped.
- No ticket persistence.
