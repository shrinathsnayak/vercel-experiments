Voice Notes Lab turns a pasted transcript into chapters, a short summary, and action items via AI SDK `generateObject`. Audio upload is stubbed — only text is processed. Missing AI keys return `503` with setup guidance; the demo never fabricates model output.

## Features

- **Transcript - structure** – chapters with start hints, summary, actions.
- **Audio stub** – documents the intended upload path without claiming STT.
- **Honest `503`** when AI Gateway / OpenAI is not configured.

## Server Reference

### `POST /api/voice-notes`

```json
{ "transcript": "…", "audioStub": true }
```

#### Success (`200`)

```json
{
  "result": {
    "summary": "…",
    "chapters": [{ "title": "…", "startHint": "early", "summary": "…" }],
    "actions": ["…"]
  },
  "provider": "ai-gateway"
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Missing transcript |

## Implementation Details

<Steps>
<Step>

### Validate

Truncate transcript; require AI provider or return `AI_SETUP_BODY`.

</Step>
<Step>

### Structure

`generateObject` with a Zod schema; `clampVoiceResult` caps chapters/actions.

</Step>
</Steps>

## Use Cases

- Meeting note - action extraction prototype.
- Teach generateObject schemas for nested lists.
- Pair with Notes to Actions Lab persistence.

## Limitations

- No real speech-to-text.
- Demo-scale transcript length cap.
- No auth on public deploys.
