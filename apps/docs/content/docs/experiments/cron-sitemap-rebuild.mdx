Cron job rebuilds `sitemap.xml` from a content URL list with Neon/Blob/memory persistence.

## Features

- Standalone Next.js app under `apps/experiments/cron-sitemap-rebuild/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## API Reference

### `GET|POST /api/cron/sitemap · GET /sitemap.xml`

```
Cron Authorization bearer when CRON_SECRET set
```
