Run the same user prompt under two system prompts, compare outputs side-by-side, and score with a judge model.

## Features

- Standalone Next.js app under `apps/experiments/prompt-ab-eval/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## Server Reference

### `POST /api/eval`

```
{ "systemA", "systemB", "user" }
```
