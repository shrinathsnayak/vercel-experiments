Screenshot to Ticket is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Vision - structured bug ticket
- Severity + repro steps
- Honest 503 without AI

## Server Reference

### `POST /api/ticket`

```json
multipart/form-data: file=<image>
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing image |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not a real issue tracker.
- 4MB image cap.
- Model may miss UI nuance.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/screenshot-to-ticket/`.
