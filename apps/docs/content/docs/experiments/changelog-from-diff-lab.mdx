Changelog from Diff Lab turns a pasted PR diff or commit log into `{ customerFacing, internalNotes }` via `generateObject`. Outputs are capped and treated as drafts. Missing AI keys return `503` - nothing is fabricated.

## Features

- **Diff - dual changelog** – customer-facing + internal notes.
- **Length caps** – ~20k chars of input; 12 bullets per list.
- **Sample commit/diff** – Redis FAQ cache example.
- **Honest `503`** when AI is unavailable.

## Server Reference

### `POST /api/changelog`

```json
{ "diff": "commit ...\ndiff --git ..." }
```

#### Success (`200`)

```json
{
  "customerFacing": ["Faster FAQ answers via cache"],
  "internalNotes": ["Requires Upstash Redis env"],
  "provider": "ai-gateway"
}
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Empty diff |

## Implementation Details
