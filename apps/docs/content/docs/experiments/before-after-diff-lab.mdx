Before After Diff Lab is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Two-image vision diff
- Structured change list
- Honest 503

## Server Reference

### `POST /api/diff`

```json
multipart: before=<image>&after=<image>
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing images |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not pixel-perfect QA.
- 4MB per image.
- Model may miss subtle diffs.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/before-after-diff-lab/`.
