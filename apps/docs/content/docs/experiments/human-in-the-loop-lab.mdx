Generate an email draft with AI, edit it in the UI, then approve a POST to your webhook. Missing AI keys return `503`.

## Features

- Standalone Next.js app under `apps/experiments/human-in-the-loop-lab/`.
- Honest degradation when optional services are missing.
- Unit-tested helpers in `logic.ts`.

## Server Reference

### `POST /api/propose · POST /api/send`

```
{ "brief": "..." } / { "email": {...}, "webhookUrl": "..." }
```
