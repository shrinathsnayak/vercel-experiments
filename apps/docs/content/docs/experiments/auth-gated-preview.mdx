Auth-Gated Preview is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Password unlock sets preview cookie
- Draft vs published content
- Lock clears cookie

## API Reference

### `POST /api/unlock · GET /api/content · POST /api/lock`

```json
{ "password": "preview" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `401` | Bad password |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Single shared password.
- No user accounts.
- Educational gate only.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/auth-gated-preview/`.
