PDF Redaction Helper is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Suggest PII spans with types
- Local highlight preview helpers
- Explicit imperfect-redaction caveat

## Server Reference

### `POST /api/redact`

```json
{ "text": "Contact Jane Doe at jane@acme.io" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing text |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not a compliance-certified redaction product.
- Models miss and invent spans — always review.
- No binary PDF rewrite in this lab.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/pdf-redaction-helper/`.
