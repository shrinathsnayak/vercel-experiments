Recipe from Fridge is a Batch G vertical mini composition lab. Pure helpers live in `logic.ts`; AI calls return an honest `503` when no provider is configured.

## Features

- Local ingredient parsing
- generateObject recipes
- Honest 503

## Server Reference

### `POST /api/recipes`

```json
{ "ingredients": "..." }
```

| Status | Cause |
| --- | --- |
| `200` | Success (or stream) |
| `400` | Missing / invalid input |
| `503` | No AI provider (`AI_GATEWAY_API_KEY` or `OPENAI_API_KEY`) |




## Limitations

- Not nutrition advice.
- Capped ingredient list.
- No shopping APIs.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `AI_GATEWAY_API_KEY` | Yes (or OpenAI) | Preferred AI provider |
| `OPENAI_API_KEY` | No | Fallback |
| `AI_MODEL` | No | Model override |
