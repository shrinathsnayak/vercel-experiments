Notes to Actions Lab extracts `{ title, owner?, due?, status }` items via `generateObject`, then persists them to Neon (`experiment_actions`) when `DATABASE_URL` is set. Without Postgres it keeps an in-memory session list and shows a UI note. Toggle status with `PATCH`. Missing AI keys return `503`.

## Features

- **Meeting notes - actions** – capped notes (~12k chars), up to 20 items.
- **Neon or memory** – `experiment_actions` table when configured; honest in-memory fallback.
- **Status toggle** – mark done / reopen without regenerating.
- **Sample standup notes** – prefilled owners and dues.
- **Honest `503`** when AI Gateway / OpenAI is not configured.

## Server Reference

### `POST /api/actions`

```json
{ "notes": "..." }
```

#### Success (`200`)

```json
{
  "actions": [
    { "id": "a-1", "title": "Ship docs", "owner": "Alex", "due": "Friday", "status": "open" }
  ],
  "storage": "neon",
  "provider": "ai-gateway"
}
```

### `GET /api/actions`

Lists persisted actions (`storage: neon | memory`).

### `PATCH /api/actions`

```json
{ "id": "a-1", "status": "done" }
```

| Status | Cause |
| --- | --- |
| `503` | No AI provider (POST) |
| `400` | Empty notes / invalid patch |
| `404` | Unknown action id |

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `AI_GATEWAY_API_KEY` | Yes (or `OPENAI_API_KEY`) | Preferred provider |
