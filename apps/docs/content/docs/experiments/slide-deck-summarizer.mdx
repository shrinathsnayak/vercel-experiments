Slide Deck Summarizer accepts pasted text or `.txt`/`.md`/`.pdf` uploads (`unpdf` for PDFs), splits slides on delimiters, and streams a per-slide bullet summary plus executive brief via `streamText`. Missing AI keys return `503`.

## Features

- **Paste or PDF** – text extract with unpdf.
- **Slide splitting** – `---` / “Slide N” / paragraph heuristics.
- **streamText summary** – bullets + executive brief.
- **Cancel** – abort mid-stream.
- **Honest `503`** when AI is unavailable.

## Server Reference

### `POST /api/summarize`

JSON `{ "text": "..." }` or multipart with `text` + optional `file`.

#### Success (`200`)

Plain text token stream (`text/plain`) with `x-slide-count` header.

| Status | Cause |
| --- | --- |
| `503` | No AI provider |
| `400` | Empty source / PDF parse failure |
