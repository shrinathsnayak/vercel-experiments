Job Queue Lite enqueues string payloads into Redis (or process memory), advances one job per drain step via Cron/`?run=1`, and shows a progress UI. Include `fail-me` in a payload to simulate failure.

## Features

- **Enqueue** – Redis list-as-JSON or shared memory store.
- **Drain** – Cron Route Handler advances progress in chunks.
- **Progress UI** – status, percent bar, error text.
- Honest note when Redis is missing.

## API Reference

### `POST /api/queue`

```json
{ "payload": "resize-avatar:user-42" }
```

### `GET /api/queue`

Lists jobs (`storage: redis | memory`).

### `GET /api/drain?run=1` / `POST /api/drain`

Drains one step. Production requires `Authorization: Bearer CRON_SECRET`.

| Status | Cause |
| --- | --- |
| `400` | Missing payload |
| `401` | Cron auth failed |

## Use Cases

- Teach Cron workers without a full queue product.
- Prototype job progress UX.
- Compare with Vercel Queues (`queues-lab`).

## Limitations

- Not a durable multi-instance queue without Redis.
- Single-step drain is intentional (demo clarity).
- No retries/backoff beyond the simulated failure path.
