Diagram to Mermaid is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Text and/or image - Mermaid
- Explicit accuracy caveat
- Honest 503

## Server Reference

### `POST /api/mermaid`

```json
{ "description": "User to API to DB" }
```

| Status | Cause |
| --- | --- |
| `200` | Success |
| `400` | Missing input |
| `503` | No AI provider |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not a guaranteed-correct diagram converter.
- Complex diagrams may need edits.
- No live Mermaid renderer in the API.

## Use in your project

Copy the Route Handler(s) and `logic.ts` from `apps/experiments/diagram-to-mermaid/`.
