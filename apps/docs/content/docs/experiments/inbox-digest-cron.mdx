Inbox Digest Cron seeds sample messages into Redis (or process memory), then a Cron-style Route Handler builds a digest. With AI configured it summarizes; otherwise it deterministically joins subjects/bodies. Cron invocations check `CRON_SECRET`.

## Features

- **Seed inbox** – sample partner/ops messages.
- **Cron digest** – `vercel.json` schedule hits `/api/digest`.
- **AI or deterministic** – never invents messages when AI is missing.
- **Redis or memory** – honest UI notes when Redis is absent.

## Server Reference

### `POST /api/seed`

Seeds sample messages.

### `GET /api/digest?run=1`

Runs a digest (authorize with `Bearer CRON_SECRET` in production). Without `run=1`, returns the last digest.

### `POST /api/digest`

Cron-friendly run (same auth rules).

| Status | Cause |
| --- | --- |
| `401` | Missing/invalid `CRON_SECRET` |
