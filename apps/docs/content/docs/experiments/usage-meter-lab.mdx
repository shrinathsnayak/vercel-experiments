Usage Meter Lab is a Wave 3 Batch H composition lab. Pure helpers live in `logic.ts`; missing providers or stores degrade honestly (never fabricate AI output).

## Features

- Soft + hard limits
- Per-session counters
- Redis/memory store

## API Reference

### `POST /api/meter · GET /api/meter`

```json
{ "sessionId": "demo-1" }
```

| Status | Cause |
| --- | --- |
| `200` | Allowed / soft warning |
| `429` | Hard limit |
| `400` | Missing session |

## Implementation Details

<Steps>
<Step>

### Validate

Inputs are length-capped in `logic.ts`; APIs return `400` for missing fields.

</Step>
<Step>

### Run

Route Handlers compose AI SDK, Redis/Neon, or `ImageResponse` as documented. Fallbacks include honest notes.

</Step>
</Steps>

## Limitations

- Not billing-grade metering.
- No stripe invoices.
- Demo caps only.
