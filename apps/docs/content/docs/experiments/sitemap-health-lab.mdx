Sitemap Health Lab fetches a sitemap XML, extracts up to N `<loc>` URLs, then checks each status with a minimum delay between requests. No AI provider required.

## Features

- **Sitemap loc extraction** – http(s) only
- **Rate-limited checks** – `MIN_DELAY_MS` between link fetches
- **Summary stats** – ok / failed / avgMs

## API Reference

### `POST /api/health`

```json
{ "sitemapUrl": "https://vercel.com/sitemap.xml", "sample": 8 }
```

| Status | Cause |
| --- | --- |
| `400` | Validation / upstream / empty input |

## Use Cases

- Learn composition patterns for this lab’s stack.
- Prototype before wiring production auth and quotas.
- Deploy the standalone app as a reference implementation.

## Limitations

- Demo-scale caps on input size and output counts.
- No auth / rate limits on public deploys.
- Treat outputs as drafts, not production truth.

## Use in your project

Copy the Route Handler and `logic.ts` helpers from `apps/experiments/sitemap-health-lab/`. Wire your own persistence and auth as needed.
