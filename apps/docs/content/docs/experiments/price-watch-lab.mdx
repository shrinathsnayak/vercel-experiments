Price Watch Lab is a Batch G vertical mini composition lab. Pure helpers live in `logic.ts`; AI calls return an honest `503` when no provider is configured.

## Features

- parsePrice helper
- Redis/memory watch list
- AI notes without fake markets

## Server Reference

### `POST /api/watch`

```json
{ "watch": "..." }
```

| Status | Cause |
| --- | --- |
| `200` | Success (or stream) |
| `400` | Missing / invalid input |
| `503` | No AI provider (`AI_GATEWAY_API_KEY` or `OPENAI_API_KEY`) |

Optional Redis persistence endpoints degrade to in-memory when unset.


## Limitations

- No guaranteed price scrape.
- Educational only.
- Memory fallback cold-starts.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `AI_GATEWAY_API_KEY` | Yes (or OpenAI) | Preferred AI provider |
| `OPENAI_API_KEY` | No | Fallback |
| `AI_MODEL` | No | Model override |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | No | Persistence |
