# Vercel Experiments

Vercel Experiments is an independent community project for discovering, exploring, and deploying small interactive experiments in the Next.js and Vercel ecosystem.

It is **not** an official Vercel product and is not affiliated with or endorsed by Vercel.

## What you will find

- Standalone experiment apps you deploy or run locally
- Practical explanations of platform capabilities
- Clear distinctions between Next.js features and Vercel-specific behavior
- Honest simulation labels when live infrastructure is unavailable
