## Process

1. Open an issue for large proposals.
2. Keep pull requests focused.
3. Follow experiment conventions.
4. Include tests for non-trivial logic.
5. Update docs when behavior changes.

## Code of conduct

Be respectful and constructive. Harassment and bad-faith contributions are not welcome.

## Security reports

Email security concerns privately to the maintainers listed in `SECURITY.md`. Provide reproduction steps and impact. Do not open public issues for exploitable vulnerabilities.
